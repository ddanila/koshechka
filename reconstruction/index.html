What has been reconstructed?

Six acceleration branches, remembered per-leg coefficients, four-leg phase coupling, constrained leg geometry, relative coordinate frames, tapered solids and orthographic binary projection. The default run walks, slows to a stop and turns its head.

Body dimensions, limb lengths, camera, character grid and movement schedules are inferred. Numerical repairs are documented in the implementation notes. This is a working reconstruction, not a claim to have recovered the missing original program.
